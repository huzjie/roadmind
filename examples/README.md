# RoadMind 示例

按编号顺序运行，每个示例可独立执行：

```bash
python examples/01_quickstart.py
python examples/02_perception_planning.py
python examples/03_serve_client.py
python examples/04_vqa.py
python examples/05_safety_check.py
python examples/06_eval.py
python examples/07_dataset.py
python examples/08_custom_model.py
```

示例 1-8 默认使用 Mock 后端，无需 GPU / 模型下载即可运行。
